# Polaris Digital Solution — developer brand assets

Laluan Kitani is developed by Polaris Digital Solution. These files are for the developer credit only, kept separate from the Laluan Kitani brand in [`../laluan-kitani/`](../laluan-kitani/).

## Variants

Each variant comes as SVG (web and app) and EPS (print).

| Variant | Contents | Size (viewBox) |
| --- | --- | --- |
| `combo` | Mark + "Polaris" wordmark + "Digital Solution" | 820 × 220 |
| `mark` | Bracket-and-star symbol only | 220 × 220 |
| `wordmark` | Text only | 720 × 220 |

| Suffix | Background | Ink | Use on |
| --- | --- | --- | --- |
| `-light` | Solid `#E8ECF5` | Navy `#0A1230`, star `#9BA8FF` | As a tile, anywhere |
| `-dark` | Solid `#0A1230` | Light | As a tile, anywhere |
| `-mono-light` | Transparent | Navy `#0A1230` | Light backgrounds |
| `-mono-dark` | Transparent | Pale `#E8ECF5` | Dark backgrounds |

## Where the credit appears

- **GitHub README**: `combo-mono-light` / `combo-mono-dark`, switched by colour scheme.
- **In the product**: keep it secondary. Use a small "Developed by Polaris Digital Solution" line in the app's Settings/About screen, the website footer and the admin dashboard footer.
- **Never** put the Polaris mark inside the Laluan Kitani logo or lockup, or on driving screens. Follow the co-branding rule in the brand book: logos side by side at equal height, separated by a thin divider.
